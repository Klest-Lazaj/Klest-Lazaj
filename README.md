## About me

I’m a full-stack software engineer building products from first idea to production:
clear interfaces, dependable APIs, thoughtful data models, secure auth, and
infrastructure that holds up as a product grows.

My work spans SaaS platforms, marketplaces, business systems, AI-powered tools,
and custom integrations.
